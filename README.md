# Blog App

A simple blog web application built with Node.js, Express, and EJS.

## About

This project is a basic full-stack-style blog app where users can create, view, edit, and delete blog posts. It uses Express for the backend server and EJS for rendering dynamic pages.

The app currently stores posts in memory, so posts may reset when the server restarts unless database support is added later.

## Features

- Create blog posts
- View blog posts
- Edit existing posts
- Delete posts
- View public posts
- EJS templating
- Express routing
- Static assets served from the `public` folder

## Tech Stack

- Node.js
- Express.js
- EJS
- Method Override
- HTML
- CSS
- JavaScript
